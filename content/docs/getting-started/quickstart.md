# Quickstart

Follow these steps to get value in minutes.

## 1. Create a new idea

Use `+ New Idea` from the sidebar to start a fresh validation thread.

## 2. Complete checkpoints

Answer questions across the validation checkpoints to generate a reliable score.

## 3. Run interviews

Use interviews to collect real customer evidence and reduce assumption risk.

## 4. Review score and insights

Open score and analytics views to identify weak assumptions and next actions.
